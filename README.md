<h1>GaseousMarble</h1>

Draw Unicode text in [GameMaker 8.2](https://gm82.cherry-treehouse.com/#News), with high performance and rich features.

> \[!warning\]
> 
> Minimum system requirement: Windows 10, Version 1903.

## Development

1. Install [Visual Studio 2026](https://visualstudio.microsoft.com/) with MSVC Build Tools for x64/x86 Preview.
2. Install [vcpkg](https://vcpkg.io/en/).
3. `vcpkg install wil:x86-windows`.
4. Build clang-format 24 from [LLVM](https://github.com/llvm/llvm-project/) if formatting is needed.

<h1>Reference</h1>

<h2><code>generate_font(font_path, sprite_path, font_size, charset, dense, smoothing, fill, stroke_width, stroke_fill, shadow_offset, shadow_fill)</code></h2>

Generate a font from font files.

<h2><code>gm_font(key, sprite_path)</code></h2>

Add a font generated by `tools/generate_font`.

| **Returned Value** | **Description** |
| --- | --- |
| `1` | Font already exists |
| `0` | OK |
| `-1` | Failed to open file |
| `-2` | Invalid header |
| `-3` | Data corrupted |
| `-4` | Failed to load sprite |
| `-100` | Invalid argument |

<h2><code>gm_free(key)</code></h2>

Free a font.

| **Returned Value** | **Description** |
| --- | --- |
| `1` | Font not found |
| `0` | OK |

<h2><code>gm_clear()</code></h2>

Free all fonts.

<h2><code>gm_draw(x, y, str)</code></h2>

Draw a UTF-8 string.

| **Returned Value** | **Description** |
| --- | --- |
| `0` | OK |
| `-1` | Failed to decode |
| `-2` | Failed to word break |
| `-3` | Invalid option |
